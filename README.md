# Student Management System

A console-based Java application to manage student records, built with Java, JDBC and MySQL.

## Features
- Add, view, update and delete students
- Student fields: ID, name, email, mobile, branch
- Total student count
- Search by Student ID or name
- Input validation and duplicate email/mobile handling

## Tech Stack
Java, JDBC, MySQL, Maven

## How to Run
1. Install JDK, MySQL and IntelliJ IDEA
2. Create the `student_db` database and `students` table in MySQL
3. Set your MySQL password in `DBConnection.java`
4. Run `Main.java`
